Programming Languages

HTML
HTML stands for Hypertext Markup Language. It is used to create the structure of web pages.
CSS
CSS stands for Cascading Style Sheets. It is used to style and layout web pages.
JavaScript
JavaScript is a programming language that allows you to create dynamic and interactive content on web pages.
Python
Python is a high-level programming language known for its simplicity and readability. It is widely used in web development, data analysis, artificial intelligence, and more.
